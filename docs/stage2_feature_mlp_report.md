# 阶段二实验报告：多特征融合 MLP

## 一、实验目标

在阶段一纯文本基线基础上，引入作者信息和评论网络特征，通过多特征融合提升假新闻检测性能，并验证各特征的贡献。

## 二、模型设计

### 输入特征

| 特征 | 维度 | 来源 |
|------|------|------|
| 新闻文本 | 1024 | BERT嵌入 |
| 作者信息 | 1024 | 作者历史文本的BERT嵌入 |
| 评论网络 | 1024 | 评论文本BERT嵌入的平均 |

### 融合策略：残差连接

```
主分支:   news_feat = MLP_news(新闻)           → 256维
残差分支: extra_feat = MLP_extra(作者, 评论)  → 256维
输出:     combined = news_feat + extra_feat   → 分类
```

**残差连接优势**: 即使额外特征无效，模型也能退化为纯文本基线，保证性能不低于阶段一。

### 网络结构

```
主分支 (新闻):
  输入(1024) → Linear(256) → ReLU → Dropout → Linear(256) → ReLU → Dropout

残差分支 (作者+评论):
  输入(2048) → Linear(256) → ReLU → Dropout → Linear(256) → ReLU → Dropout

融合 + 分类:
  combined = 主分支 + 残差分支 → Linear(6)
```

### 模型规模

| 项目 | 数值 |
|------|------|
| 总参数量 | 920,070 |
| 主分支层数 | 2 |
| 残差分支层数 | 2 |
| 隐藏层维度 | 256 |
| Dropout率 | 0.5 |

## 三、实验设置

| 数据集 | 样本数 |

## 四、消融实验结果

### 测试集性能对比

| 特征组合 | 测试集准确率 | 运行次数 |
|----------|-------------|----------|
| 新闻 (阶段一) | 28.71% ± 1.01% | 7 |
| 新闻 + 作者 | 28.82% ± 0.11% | 5 |
| 新闻 + 评论 | 28.80% ± 0.12% | 6 |
| 新闻 + 作者 + 评论 | 28.80% ± 0.12% | 4 |

### 与阶段一对比

| 指标 | 阶段一 (纯文本) | 阶段二 (多特征) | 变化 |
|------|----------------|----------------|------|
| 测试集准确率 | 28.71% | 28.82% | +0.11% |
| 参数量 | 681,480 | 920,070 | +35% |

## 五、结果分析

### 主要发现

1. **额外特征贡献有限**: 加入作者信息和评论特征后，测试集准确率仅从28.71%微升至28.82%，提升不足0.2%，统计上无显著差异。

2. **验证集与测试集差异**: 验证集准确率约为41%，但测试集准确率仅为28.8%，表明模型在验证集上存在过拟合。

3. **特征融合未达预期**: 残差连接设计虽能保证不退化，但未能有效利用额外特征提升泛化性能。

### 可能原因

1. **数据分布差异**: 验证集和测试集的数据分布可能存在差异
2. **特征质量问题**: 作者和评论嵌入可能未能有效捕获与假新闻相关的特征
3. **模型容量与过拟合**: 增加参数量后更容易在验证集上过拟合

### 局限性

- 当前融合方式为简单残差连接，未充分挖掘特征间交互
- 评论特征采用简单平均，未考虑评论时序和用户关系
- 需要进一步分析验证集与测试集分布差异

## 六、结论

阶段二实验表明，简单的特征拼接或残差融合方式未能有效利用作者和评论特征提升测试集性能。下一步需要探索更有效的特征融合策略，或引入图神经网络建模特征间的关系。
