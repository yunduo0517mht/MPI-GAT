# 阶段三实验报告：基础图神经网络

## 一、实验目标

利用基础图神经网络（GCN/GAT）建模新闻-评论二部图关系，证明图神经网络对假新闻检测有效。

---

## 二、模型设计

### 图结构

采用**新闻-评论二部图**：
- 节点类型：新闻节点 + 评论节点
- 边：评论属于某条新闻
- 每个样本是一个小图：1条新闻 + 多条评论（平均6条）

### GCN 模型架构

```
评论特征 ──→ 线性变换 ──→ 归一化聚合 ──┐
                                      │
新闻特征 ─────────────────────────────┼──→ 残差融合 ──→ MLP ──→ 分类
                                      │
                              门控 ←──┘
```

**聚合方式**：GCN 风格的平均聚合
```
h_news = 1/N * Σ W * h_comment_i
```

### GAT 模型架构

```
评论特征 ──→ 线性变换 ──→ 注意力聚合 ──┐
                                      │
新闻特征 ─────────────────────────────┼──→ 残差融合 ──→ MLP ──→ 分类
                                      │
                              门控 ←──┘
```

**注意力计算**：
```
α_ij = softmax(LeakyReLU(a^T [Wh_news || Wh_comment_j]))
h_news = Σ α_ij * Wh_comment_j
```

### 模型规模

| 项目 | 数值 |
|------|------|
| 输入维度 | 1024 |
| 隐藏层维度 | 512, 256 |
| 输出类别 | 6 |
| GAT 注意力头 | 1 |
| Dropout 率 | 0.5 |
