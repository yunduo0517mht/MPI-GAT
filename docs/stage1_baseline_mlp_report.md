# 阶段一实验报告：Baseline MLP

## 一、实验目标

建立假新闻检测的文本基线模型，仅使用新闻文本内容进行分类，为后续多特征融合提供对比基准。

## 二、模型设计

### 输入输出
- **输入**: 新闻文本的BERT嵌入向量 (1024维)
- **输出**: 6类标签分类
  - true / mostly-true / half-true / barely-true / false / pants-fire

### 网络结构

```
输入层 (1024) → 全连接层 (512) → 全连接层 (256) → 输出层 (6)
```

### 模型规模

| 项目 | 数值 |
|------|------|
| 总参数量 | 681,480 |
| 隐藏层层数 | 2 |
| 隐藏层维度 | 512, 256 |
| Dropout率 | 0.5 |

## 三、实验设置

### 数据集：LIAR

| 数据集 | 样本数 |
|--------|--------|
| 训练集 | 10,236 |
| 验证集 | 1,284 |
| 测试集 | 1,283 |

### 训练配置

| 配置项 | 值 |
|--------|-----|
| 训练轮数 (Epochs) | 50 (Early Stopping) |
| 批大小 (Batch Size) | 32 |
| 学习率 | 1e-4 |
| 优化器 | Adam |
| 早停耐心值 | 10 |
| 运行次数 | 7次取平均 |

## 四、实验结果

### 总体性能

| 指标 | 结果 |
|------|------|
| **准确率 (Accuracy)** | **28.71% ± 1.01%** |
| F1值 (Macro) | 27.10% ± 3.33% |
| F1值 (Weighted) | 27.24% ± 2.78% |
| 精确率 (Macro) | 30.76% ± 3.00% |
| 召回率 (Macro) | 27.95% ± 1.81% |

### 各类别性能

| 类别 | F1值 |
|------|------|
| true (真实) | 23.77% |
| mostly-true (大部分真实) | 30.50% |
| half-true (半真半假) | 29.48% |
| barely-true (几乎不真) | 16.01% |
| **false (虚假)** | **33.32%** |
| pants-fire (完全造假) | 29.51% |

## 五、结果分析

### 主要发现

1. **基线性能**: 准确率28.71%，显著高于随机猜测(16.67%)，验证了文本特征对假新闻检测的有效性。

2. **类别差异**: "false"类别检测效果最好(33.32%)，"barely-true"最差(16.01%)，表明虚假新闻在文本层面有一定可辨识特征。

3. **局限性**: 仅依赖文本信息，缺乏作者可信度、传播网络等社交特征，整体性能有待提升。

### 下一步工作

阶段二将引入作者信息和评论网络特征，通过多特征融合提升检测性能。
